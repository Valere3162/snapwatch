API REFERENCE

snapwatch API

Monitor any URL for changes. Receive a structured webhook with a diff and screenshot the moment something changes. No cron jobs, no infrastructure — one POST to register a watch.

Base URL https://api.snapwatch.dev Version 1.0 Format JSON Auth Bearer token

Overview

Snapwatch monitors web pages for content changes and delivers real-time webhook notifications when something changes. You configure a watch — a URL, a delivery endpoint, and an optional CSS selector — and snapwatch handles the scheduled checks, content diffing, screenshot capture, and webhook delivery with retry logic.

Common use cases:

  • Monitor competitor pricing pages and receive an alert when text changes.
  • Track government or regulatory pages for policy updates.
  • Watch job boards, product pages, or news sources without manual refreshing.
  • Build internal alerting pipelines by piping snapwatch webhooks into Slack, PagerDuty, or custom backends.

Authentication

Every authenticated endpoint requires a Bearer token in the Authorization header. API keys are provisioned at account creation and are linked to a plan (starter or pro).

Key format: sw_live_ followed by 32 hex characters.

HTTP Authorization header 
Authorization: Bearer sw_live_4a8f2c91b3e70d56a1f9c82b4e371d08
⚠

Keys are stored as SHA-256 hashes on the server. The raw key is shown once at creation and cannot be retrieved afterwards. If you lose your key, rotate to a new one via the dashboard.

409Conflict — a watch for this URL already exists on your account
422Unprocessable — field value fails business validation
429Too many watches — watch limit reached for your plan
500Internal server error — unexpected failure on snapwatch's side

Webhook Events

When a watch detects a change, snapwatch delivers a POST to your webhook_url. All event types share the same base payload shape.

Delivery headers

HeaderValue
Content-Typeapplication/json
User-AgentSnapwatch/1.0 (+https://snapwatch.dev)
X-Snapwatch-EventThe event type
X-Snapwatch-Watch-IdUUID of the triggering watch

changedPage changed

Fired when the monitored content hash differs from the previous check.

JSONPayload
{
  "event_type":   "changed",
  "watch_id":     "019234ab-cdef-7890-1234-56789abcdef0",
  "url":          "https://acme.com/pricing",
  "changed_at":   "2026-09-07T14:00:01.000Z",
  "diff_summary": "Price changed from $49 to $59 in #pricing-table",
  "screenshot_url": "https://cdn.snapwatch.dev/screenshots/abc123.png"
}

blockedSite blocked snapwatch

Fired when the target site blocks snapwatch (CAPTCHA, IP block, 403/429). The watch's check_status is set to "blocked". Visit the dashboard to investigate and re-enable.

JSONPayload
{
  "event_type":   "blocked",
  "watch_id":     "019234ab-...",
  "url":          "https://acme.com/pricing",
  "changed_at":   "2026-09-07T15:00:00.000Z",
  "diff_summary": "Site returned 403 Forbidden — automated access may be blocked",
  "screenshot_url": null
}

errorCheck failed

Fired when a check fails for a non-blocking reason (DNS failure, timeout, unexpected HTTP error). The watch continues on its normal schedule.

JSONPayload
{
  "event_type":   "error",
  "watch_id":     "019234ab-...",
  "url":          "https://acme.com/pricing",
  "changed_at":   "2026-09-07T16:00:00.000Z",
  "diff_summary": "Check failed: connection timed out after 30s",
  "screenshot_url": null
}

weekly_digestWeekly summary

Delivered once per week regardless of whether the page changed. The only event type with additional fields: checks_run and changes_found.

JSONPayload
{
  "event_type":   "weekly_digest",
  "watch_id":     "019234ab-...",
  "url":          "https://acme.com/pricing",
  "changed_at":   "2026-09-07T09:00:00.000Z",
  "diff_summary": "7 checks run, 1 change detected in the past 7 days",
  "screenshot_url": null,
  "checks_run":   168,
  "changes_found": 1
}

Webhook Delivery & Retry

Snapwatch sends POST to your webhook_url with a 10-second timeout. A 2xx HTTP response is required for a delivery to be considered successful.

Retry schedule

AttemptDelayTotal elapsed
1 (initial)Immediate0s
2+10 seconds~10s
3+60 seconds~70s
4+300 seconds~370s

After 4 total attempts without a successful 2xx, delivery is abandoned. webhook_delivered_at remains null. Redelivery is not available via API — design your webhook endpoint to be idempotent.

Recommendations

  • Respond 200 OK immediately, then process the payload asynchronously.
  • Use X-Snapwatch-Watch-Id + event id for idempotency.
  • If your endpoint is behind a firewall, allowlist User-Agent: Snapwatch/1.0.
  • Log webhook_delivered_at from history against your own receipt timestamps to detect gaps.

Node.js

JavaScriptCreate a watch + handle webhook
const API_KEY  = "sw_live_YOUR_KEY";
const BASE_URL = "https://api.snapwatch.dev";
const headers  = {
  Authorization:  `Bearer ${API_KEY}`,
  "Content-Type": "application/json",
};

// Create a watch
const res = await fetch(`${BASE_URL}/watches`, {
  method: "POST",
  headers,
  body: JSON.stringify({
    url:                    "https://acme.com/pricing",
    webhook_url:            "https://hooks.yourapp.com/snapwatch",
    check_interval_minutes: 30,
    css_selector:           "#pricing-table",
  }),
});
const { watch } = await res.json();
console.log("Created:", watch.id);

// Handle inbound webhook (Express)
app.post("/snapwatch", (req, res) => {
  res.sendStatus(200); // respond immediately
  const { event_type, url, diff_summary, screenshot_url } = req.body;
  if (event_type === "changed") {
    notifyTeam({ url, diff_summary, screenshot_url });
  }
});

Python

PythonCreate a watch + handle webhook
import requests
from flask import Flask, request, jsonify

session = requests.Session()
session.headers.update({
    "Authorization": "Bearer sw_live_YOUR_KEY",
    "Content-Type":  "application/json",
})

# Create a watch
resp = session.post("https://api.snapwatch.dev/watches", json={
    "url":                    "https://acme.com/pricing",
    "webhook_url":            "https://hooks.yourapp.com/snapwatch",
    "check_interval_minutes": 30,
    "css_selector":           "#pricing-table",
})
watch = resp.json()["watch"]
print(f"Created: {watch['id']}")

# Handle inbound webhook (Flask)
app = Flask(__name__)

@app.post("/snapwatch")
def snapwatch_webhook():
    data = request.get_json()
    if data["event_type"] == "changed":
        print(f"[CHANGED] {data['url']}: {data['diff_summary']}")
    return jsonify({"received": True}), 200
